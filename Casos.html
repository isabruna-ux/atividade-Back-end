B) Elaboração do caso de teste

Um caso de teste é um conjunto de condições, dados de entrada e resultado esperado, criado para verificar um comportamento específico do sistema.

Conceito

Um bom caso de teste é claro, repetível, independente e tem um único resultado esperado verificável.

Técnicas comuns: partição de equivalência (agrupar entradas que se comportam igual), análise de valor limite (testar as bordas) e tabela de decisão (combinar condições).

Estrutura básica

  1. Identificador e título, como CT-001 Cadastrar usuário válido.
  2. Pré-condições, como banco limpo e token válido.
  3. Passos e dados de entrada.
  4. Resultado esperado, com status HTTP e corpo da resposta.
  5. Resultado obtido e situação (passou ou falhou).

Exemplos: cadastro de usuário (POST /usuarios)

Do caso de teste ao código

test("CT-002 rejeita e-mail inválido", async () => {
  const r = await api.post("/usuarios", { nome: "Eduardo", email: "eduardo.com", senha: "12345678" });
  expect(r.status).toBe(400);
  expect(r.body.erro).toMatch(/e-mail/);
});
Dica: erros comuns ao escrever casos

Casos vagos ("testar login"), vários resultados esperados num só caso e dados que dependem de outros casos.
