Execução, monitoramento e controle

Planejar não basta. É preciso rodar os testes, observar o andamento e corrigir a rota quando algo foge do plano.

C) Execução do programa

  1. Preparar o ambiente e os dados de teste (banco, variáveis, serviços externos simulados).
  2. Executar os casos, manualmente ou por automação.
  3. Registrar o resultado obtido de cada caso: passou, falhou ou bloqueado.
  4. Abrir incidentes para cada falha, com evidências.
  5. Reexecutar após a correção (teste de confirmação) e rodar a regressão.
$ npm test -- --coverage
$ curl -i -X POST localhost:3000/usuarios -d '{"email":"ana.com"}'

D) Monitoramento e controle

Monitorar é comparar o realizado com o planejado. Controlar é agir sobre o desvio.

MétricaO que mostraAção de controle
Casos executados / planejadosProgressoRealocar pessoas se estiver atrasado
Taxa de aprovaçãoQualidade atualPriorizar correções
Defeitos por severidadeRiscoBloquear liberação se houver críticos
Cobertura de códigoQuanto foi exercitadoCriar casos para trechos sem cobertura

Ferramentas úteis: Jest ou JUnit, Postman, Jenkins ou GitHub Actions, Grafana e Jira.
